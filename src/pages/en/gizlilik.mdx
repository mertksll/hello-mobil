<h1>Privacy</h1>
<h2>Information stored on your device</h2>
<p>The theme preference (tema), cart (kampus-cart) and order history (kampus-orders) are stored in this browser’s localStorage. Orders include coffee options, classroom details, amount, code and date. Records do not expire automatically.</p>
<h2>Form and links</h2>
<p>The contact form only displays a completion notice and clears its fields; it does not send or store their contents. The app adds no analytics or tracking cookies. External GitHub links follow that site’s terms. A web hosting provider may keep its own access logs.</p>
<h2>Deletion and security</h2>
<p>The profile delete button removes order history. Clear the browser’s site data to remove all records including the theme. localStorage is not an encrypted vault; other people using the device may access it. Do not enter real or sensitive personal information.</p>
<h2>KVKK / data protection notice</h2>
<p>This text describes how the current version uses data. Records stay on this device and are not transferred to an external server by the app. This notice will be updated if data handling changes. Last updated: 9 October 2026.</p>
<h2>Profile and favorites</h2>
<p>Your display name, preferred cafe and classroom are stored locally as kampus-profile; favorite product IDs use kampus-favorites. The profile history-delete action removes only orders and preserves the cart, profile, favorites and theme. Clear the browser’s site data to remove everything.</p>
